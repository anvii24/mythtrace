# Report figures

Generated by `python -m eval.make_figures` from the saved results in `eval/results/` (no searches, no API calls).
All PNGs are 300 dpi. External = poison page on an untrusted host; insider = poison page on a trusted host.
8 external + 8 insider poison pages; answer figures use 2 LLM samples per page (16 answers per bar).

| File | Caption |
|---|---|
| `fig1_attack_retrieval.png` | Share of poison pages with a poison chunk in the top 5 for each retrieval configuration: the Jaccard query-copy check removes every external poison page, but 62% of insider pages still reach the top 5 even with all defenses. |
| `fig2_alpha_sweep.png` | Retrieval-level attack success for BM25 + quality g(d) as the g(d) weight alpha grows from 0 to 1: external pages are only pushed out of the top 5 at alpha = 1.0, and insider pages (trusted host, high g(d)) are never affected. |
| `fig3_crowding_out.png` | Mean number of the clean top-5 chunks displaced by injected poison chunks, for BM25 without and with all defenses, before and after the fix that normalises relevance by the best unflagged chunk (all defenses, external: 1.25 -> 1.00). |
| `fig4_answer_labels.png` | Hand labels of the LLM answers to the target questions (Sonnet with no defense and all defenses, Haiku with no defense): none of the 96 answers endorses the false claim; without defenses the model mostly refutes it, with all defenses external poison no longer reaches the model (ignores). |
| `fig5_retrieval_quality.png` | Mean P@5, P@10, Hit@5 and MRR on the clean corpus (19 questions, Q10 skipped because its page is not in the crawl) for the five configurations, with the dashed best-possible line showing that P@k is capped because some expected pages have fewer than k chunks. |
| `fig6_stem_and_model.png` | Stemming on vs off for BM25 and tf-idf (left) and tf-idf (lnc.ltc cosine) vs BM25, both stemmed (right), on the clean corpus with no defenses: tf-idf finds a relevant chunk in the top 5 more often (Hit@5 0.89 vs 0.74), but BM25 ranks the first relevant chunk higher (MRR 0.73 vs 0.61). |
